# House — Software Testing

## About the project

House is a personal web application designed to help organize different aspects of household management.

The application was developed using:

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase

## Testing objective

The objective of this testing activity is to evaluate the application's behavior from a quality assurance perspective, identifying functional inconsistencies and documenting reproducible issues.

The testing process includes:

* Functional testing
* Exploratory testing
* Test case design
* Bug identification
* Bug documentation
