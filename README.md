# QA Testing Lab

A practical repository dedicated to software testing and quality assurance.

This repository documents my learning and practical application of software testing concepts through test cases, functional testing, bug reports and exploratory testing.

## Purpose

The goal of this repository is to apply software testing concepts to real applications and document the testing process in a structured and reproducible way.

## What you'll find here

* Test cases
* Functional testing
* Exploratory testing
* Bug reports
* Test scenarios
* Software testing techniques
* Practical QA documentation
